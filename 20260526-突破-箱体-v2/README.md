# 20260526 大波段 + 聚合箱体突破 EA（V2）

V2 相对 V1 的核心变化：**不再触价挂单**，改为 **K 线收盘价突破极值** 后在同一 tick **市价开仓**；**SL/TP 一律成交后**再计算并设置。

## 逻辑概要

1. **波段识别（结构）**：与 V1 相同。MA 突破 → 极值 → 有效波段（0.1%～2%，最少 3 根 K）。`InpPullbackTolerance` 默认 0.05%，仅影响结构识别时是否切断波段。

2. **大波段突破**：最新有效波段振幅 **>0.25% 且 ≤2%** 时，监测波段高/低。**有效突破 K 线**须同时满足：  
   - **首次**刺穿该极值（K 高 > 极值高点，或 K 低 < 极值低点）；  
   - **收盘确认**（破高：Close > 高点；破低：Close < 低点）。  
   满足则在同一 tick **市价开仓**。若 K 线已刺穿极值但收盘未确认（假突破/长影线），**立即标记该极值失效**，本结构内不再尝试，直至结构更新或止损后再开。  
   备注示例：`LW1168H@4689.49#4710.50,4705.20`。

3. **聚合箱体**：逻辑同上，备注前缀 `BX`。

两套机制 **同时运行、互不影响**（同一 `InpMagicNumber`，靠订单备注 `LW` / `BX` 区分）。

4. **极值占用规则**：  
   - **假突破**（刺穿极值但收盘未确认）：K 线收盘时 **立即标记极值失效**（`high_used` / `low_used`）。  
   - **有效突破且开仓**：不在收盘时标记；仅 **实际成交**（`DEAL_ENTRY_IN`）后才标记，避免未成交就锁死边界。

5. **止损（成交后设置）**  
   - 多单：确认突破 K 线的 **最低价 − 偏移点数**（默认 30 点）  
   - 空单：确认突破 K 线的 **最高价 + 偏移点数**  
   大波段与聚合箱体各自独立参数。

6. **止盈（成交后设置，二选一）**  
   - **固定点数**：开仓价 ± 止盈点数  
   - **盈亏比**：`TP 距离 = SL 距离 × 盈亏比`（默认 2.0，即 1:2）

7. **手数**：`RiskPercent` 模式下，按 **确认 K 线算出的 SL 距离**（相对预估入场价）估算每笔风险，而非固定止损点数。

8. **移动止损**（可选，大波段/箱体独立参数）：初始 SL/TP 设置完成后，浮盈 ≥ 跟踪点数时，SL 持续跟在现价后同样点数（与 V1 相同）。

9. **止损后再开**：参数 `边界止损出局后是否允许再开一单` 为 true 时，该边界 SL 出局后可再允许一次收盘突破开仓（每边界仅一次）。

10. **交易时段（北京时间 UTC+8）**：默认 **关闭**；启用后仅在 `可交易时段`（如 `15:00-02:00`）内检测收盘突破并开新仓，已有持仓照常管理 SL/TP/移动止损。多段用逗号分隔。

## V2 已移除（相对 V1）

- 触价挂单（BuyStop / SellStop 等）
- 挂单延迟预设机制
- 开仓负向滑点（挂单价偏移）

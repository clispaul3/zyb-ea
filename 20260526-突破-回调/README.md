# 20260526 有效波段回调 EA（V3）

V3 为 **顺势回调** 策略：在最新 **有效波段** 内，价格触达斐波那契式回调位时 **市价开仓**，不再使用突破确认或聚合箱体。

## 逻辑概要

1. **波段识别（结构）**：MA 突破 → 极值 → 有效波段（振幅 0.1%～2%，最少 3 根 K）。`InpPullbackTolerance` 仅影响结构是否因反向突破而切断。

2. **顺势方向**（按波段极值出现顺序）  
   - 波段 **先低后高**（上涨段）→ 只监测 **做多回调**  
   - 波段 **先高后低**（下跌段）→ 只监测 **做空回调**

3. **回调位（默认比例 0.618，可参数调整）**  
   - 做多：`买入位 = 高点 − 比例 × (高−低)`  
   - 做空：`卖出位 = 低点 + 比例 × (高−低)`

4. **触发方式**：每个 tick 检测；**Ask/Bid 触达回调位即市价进场**，触达当 tick 成交。

5. **止盈止损**：开仓时直接附带固定 **止损点数**、**止盈点数**（相对入场价）。

6. **每波段占用**：每个方向每段结构最多开一次；高低点更新后重置。可选「止损出局后再进一次」。

7. **订单备注**：`PB{振幅点数}B@回调价` / `PB{振幅点数}S@回调价`。

8. **交易时段（北京时间）**：可选；启用后仅在设定时段内开新仓。

## V3 已移除（相对 V2）

- 收盘确认突破、假突破失效逻辑
- 聚合箱体（BX）及大波段突破（LW）两套机制
- 成交后补设 SL/TP、移动止损、盈亏比止盈

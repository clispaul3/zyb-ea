# 20260606 突破反向策略 EA

交易池内有效极值**突破挂单**后顺势开仓（高点 BUY STOP 做多、低点 SELL STOP 做空）。

## 极值识别（v1.04+）

逻辑基于 `20260526_box_breakout_v2.mq5` 的波段识别，并增加同向合并与 K 线重扫：

1. **MA 突破 K 线**：收盘价从下穿上 / 从上穿下 MA。
2. **过滤连续同向突破**：保留更极端的那根。
3. **极值点**：相邻突破 K 线之间取最高/最低价；`InpPullbackTolerance > 0` 时支持容忍反向突破。
4. **合并同向极值**：连续多个高点只保留**更高**的一个，连续多个低点只保留**更低**的一个。
5. **有效波段判定**：相邻两极值振幅在设定范围内，且 K 线跨度 ≥ `InpMinWaveBars`（含两端）。
6. **真实极值重扫**：对每个有效波段，在相邻反向极值之间的 K 线内取真实最高/最低价。

## 交易极值池（v1.05+）

| 参数 | 含义 |
|------|------|
| `InpRecentValidHighCount` | 保留最近 **N 个有效高点**（独立计数，默认 3） |
| `InpRecentValidLowCount` | 保留最近 **N 个有效低点**（独立计数，默认 3） |

- `[0]` = 时间上最新的一个
- 开启 `InpHighlightRecentValid` 时，**尚未开仓**的池内极值用黄色粗箭头显示；已开仓过的不再显示

## 开仓逻辑（v1.18）

对交易池内**尚未开仓**的每个极值，持续同步突破挂单：

| 极值 | 挂单类型 | 触发价 |
|------|----------|--------|
| 高点 | **BUY STOP** | 极值价格 |
| 低点 | **SELL STOP** | 极值价格 |

- 挂单时一并设置 SL/TP（相对极值价百分比）
- 池内**每个极值仅一次机会**：成交后或价格已越过极值未成交时标记失效
- 极值滚出交易池或失效时，自动撤销对应挂单
- EA 卸载时撤销全部本 EA 挂单

## 止盈止损（v1.14+）

- **止损**：`SL距离 = 极值价 × 止损百分比`（默认 0.25%）
- **止盈**：`TP距离 = 极值价 × 止盈百分比`（默认 0.1%）
- RiskPercent 手数计算基于 SL 距离

## 手数模式

| 模式 | 说明 |
|------|------|
| 固定手数 | 使用 `InpFixedLots` |
| RiskPercent | 按结余 × 风险比例 / 止损距离计算手数 |

参数见 `参数设置.md`。

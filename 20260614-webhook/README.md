# 20260614 钉钉账户监控 EA

监控 **MT5 账户**状态，通过钉钉自定义机器人推送 Markdown 消息。

> 定位：账户维度推送（结余、净值、浮盈、持仓、平仓），非行情/策略信号。

## 文件

| 文件 | 说明 |
|------|------|
| `20260614_dingtalk_webhook.mq5` | 账户监控 EA（v1.28，单文件） |

---

## 使用步骤

1. MT5 菜单 **工具 → 选项 → 专家顾问**
2. 勾选 **允许 WebRequest 用于所列 URL**
3. 点击 **添加**，填入：

   ```
   https://oapi.dingtalk.com
   ```

4. 确定保存，**重启 MT5**（或重新加载 EA）

> 未配置此项时，日志会出现 `WebRequest err=4060`。

---

## 推送时机

| 事件 | 消息中显示 | 推送条数 |
|------|------------|----------|
| EA 挂到图表 | EA启动 | 2（快照 + 持仓） |
| EA 从图表移除 | EA停止 | 2 |
| 账户新开仓成交 | 开仓 | 2 |
| 账户平仓成交 | 平仓 | **3**（快照 + 持仓 + **平仓明细**） |
| 反手成交 | 开平仓 | **3** |

> 监控 **整个账户** 的成交，不按某个 EA 魔术号过滤。

---

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `InpWebhookUrl` | 已预填 | 钉钉机器人 Webhook 完整地址（含 `access_token`） |
| `InpSecret` | 空 | 加签密钥；机器人未开启加签时留空 |
| `InpKeyword` | `ea` | 关键词；须与钉钉机器人安全设置一致 |
| `InpAccountDisplay` | 空 | 消息中 🏦 行展示文字；留空则显示 `login@server` |

---

## 消息内容

### 消息 1：账户快照

- 账户（`InpAccountDisplay` 或默认 `login@server`）
- 触发事件（仅标题显示，如 `ea 账户快照 · 平仓`）
- 结余、净值、浮盈(亏)、持仓笔数（各一行）
- 底部：引用块显示发送时间

### 消息 2：持仓明细

- 当前未平仓位，**Markdown 表格**：品种（前 3 字母）、方向、手数、盈亏、魔
- 底部：引用块显示发送时间

### 消息 3：平仓明细（仅平仓/开平仓时）

- 本次成交对应的平仓信息，表格列与持仓明细相同
- **盈亏**为已实现盈亏（含 swap、commission）
- **方向**为被平掉的原持仓方向（BUY/SELL）
- 底部：引用块显示发送时间

示例（平仓时第三条）：

```markdown
#### 📤 ea 平仓明细 · 平仓

> 🏦 EA实测账号

| 品种 | 方向 | 手数 | 盈亏 | 魔 |
| :--- | :---: | :---: | :---: | :---: |
| XAU | SELL | 0.02 | +12.50 | 0 |

> 2026.06.14 18:10:00
```

品种简写：去掉 `.`、`_` 后缀后取前 3 个字母（如 `XAUUSD`→`XAU`）。

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `WebRequest err=4060` | 未允许 WebRequest 或未加白名单 | 配置 `https://oapi.dingtalk.com` 并重启 MT5 |
| `No WebRequest in tester` | 在策略测试器中运行 | 改在实盘/模拟盘图表上挂 EA |
| 返回关键词错误 | 消息未含机器人要求的关键词 | 检查 `InpKeyword`（默认 `ea`） |
| 返回签名错误 | 加签配置不一致 | 填写 `InpSecret` 或关闭加签 |
| PC 端看不到底部时间 | 使用了不兼容的 HTML | v1.19 起改用引用块 `>` |
| 手机端表格换行 | 钉钉 Markdown 表格列宽不可控 | 正常现象，品种已简写为 3 字母 |
| 编译报错 | 语法或编码问题 | 用 MetaEditor 打开并 F7 编译 |
| 无推送 | 未勾选允许算法交易 | EA 属性中勾选「允许算法交易」 |

---

## 安全提示

- **勿将 Webhook 地址提交到公开仓库**（含 `access_token`）
- token 泄露后应在钉钉后台 **重置** 密钥
